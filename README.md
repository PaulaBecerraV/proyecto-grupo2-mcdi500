# proyecto-grupo2-mcdi500
MCDI500 · Egresos hospitalarios por colelitiasis (K80x), Araucanía 2022 · DEIS-Minsal

Para consultar y descargar las bases de datos de egresos hospitalarios correspondientes a otros años, visite el portal de Datos Abiertos del Departamento de Estadísticas e Información de Salud (DEIS) del Ministerio de Salud de Chile. Disponible en: https://deis.minsal.cl/#datosabiertos 

**Limitaciones relacionadas con la completitud de los datos:** Las bases de datos del DEIS pueden presentar campos sin información en variables relevantes, como la región de residencia. Esta situación debe considerarse al realizar análisis desagregados territorialmente, ya que puede ocasionar una subestimación de los egresos atribuidos a cada región.
